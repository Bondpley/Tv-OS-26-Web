# About

**tvOS - Web Replica** is a browser-based reconstruction of the Apple TV interface. It includes:

- **Boot sequence** - animated Apple logo with progress bar
- **First-time setup** - handwritten "hello" in multiple languages, language picker, and room selection
- **Home screen** - parallax wallpaper, 3D-tilted app icons, focus navigation
- **Built-in apps** - Apple TV, Music, Arcade, Fitness, FaceTime, App Store, Search, Podcasts, Clock, Movies, Photos, Settings, About
- **Control Center** - Wi-Fi, AirPlay, Sleep Timer, Sound, DND toggles

Everything runs client-side. No build step, no dependencies.
